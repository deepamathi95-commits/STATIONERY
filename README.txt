Smart Stationery – run on Windows
1. Install VS Code (code.visualstudio.com) and unzip/copy the smart-stationery folder.
2. VS Code: File > Open Folder > smart-stationery.
3. Easiest: double-click index.html to open it in your browser.
   Better: install the "Live Server" extension, right-click index.html > Open with Live Server.
4. Add real photos: put images in assets/images and add  img:'assets/images/name.jpg'  to a product in js/products.js.
Authentication and checkout are simulated; passwords and card details are never stored.
